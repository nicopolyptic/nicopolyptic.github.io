--- layout: post title: SPath a domain specific query language. description: SPath appears in JOT. ---

SPath is a DSL for querying tree shaped data like JSON and XML. Queries are evaluated and matched agaist trees using LTL which can be thought as a kind of regular expression. Thinking back now from 2026, I think MongoDB needs a path language. Mongo lacks a nice path query language. The article on SPath is at Journal of Object Technology.
